# Cybersecurity Incident Analysis & Network Security Project

## Project Overview
This project was completed as part of an Amait Learning training assignment. It analyzes the **“The Quick Fix”** scenario, in which a critical software patch was deployed without prior testing and users subsequently reported login problems.

The report discusses the importance of controlled patch management, change management, testing, monitoring, and recovery planning. It also includes a proposed network topology designed using Cisco Packet Tracer.

> **Note:** This is an educational, scenario-based project. It does not claim that a real system was compromised or that a specific technical vulnerability was exploited.

## Project Objectives
- Analyze the risks of deploying patches without testing.
- Explain patch-management and change-management weaknesses.
- Propose preventive security controls and procedures.
- Design a basic network topology in Cisco Packet Tracer.
- Document IP configuration and connectivity test results.
- Prepare an estimated project budget.

## Testing Results
The documented connectivity tests between the PC, router, and server completed successfully with **0% packet loss** in the baseline test environment.

## Security Recommendations
- Test patches in a controlled environment before deployment.
- Use a documented change-approval process.
- Maintain a rollback plan before applying important changes.
- Monitor system logs and network activity.
- Restrict administrative access and protect privileged credentials.
- Maintain backups and test recovery procedures.
